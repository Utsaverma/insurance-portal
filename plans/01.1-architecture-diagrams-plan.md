## Purpose
Plan 01 delivered the **Detailed Solution Architecture** (six-swimlane layered view) and a **Bounded
Contexts** domain view. Three views the Nagarro MSAG diagram standard expects are missing:

| Review item | Missing view | MSAG category (`requirements/MSAG-Diagram-Preparation-Guidelines-v1.1.pdf`) |
|---|---|---|
| 1 | **High Level Diagram** | *Solution diagram — expressing the entire solution idea in one compact diagram* (slide 3), with numbered data-flow tags (slide 4) |
| 3 | **System Context Diagram** | *System Model — functional aspect* (slide 6a): "should cover all areas like types of users, type of integration points, type of outputs, functional modules" |
| 4 | **Logical Architecture Diagram** | *Application / Component Logical Architecture — Basic* (slide 15): vertical layer stack, left-side layer labels, cross-cutting concerns as a common column |

Outcome: one five-page deliverable that reads top-down from business context to implementation
detail, every page in the same visual family, with the SAD narrative matching it. The existing two
pages' content is unchanged — they are only re-sequenced within the file.

## Diagram Conventions (all new pages)

Reused from the existing file so all five pages read as one set:

- Uncompressed XML; `<mxfile host="app.diagrams.net" agent="Nagarro eClaims SAD">`; semantic cell IDs
  prefixed `ctx-` / `hld-` / `lg-` — no GUIDs. Canonical attribute order
  (`<mxCell id value style vertex parent>`, `<mxGeometry x y width height as>`), as on page 5.
- **Every edge carries both `source=` and `target=`.** Page 4 has six edges (`e2`, `e13`, `e19`,
  `e21`, `e23`, `e24`) with only a floating `<mxPoint as="sourcePoint">`; do not repeat that defect.
- Chrome trio, `width=1760` at `x=40`: title bar `y=0 h=40`
  (`fillColor=#1f3b57;strokeColor=none;fontColor=#ffffff;fontSize=18;fontStyle=1;align=left;spacingLeft=18`);
  meta strip `y=42 h=24` (`#eef2f6`/`#c9d3dc`, font `#1f3b57`, **the same** `Project: YCompany
  eClaims | Version 1.0 | Author: Utsav Verma (Senior Staff Engineer, Nagarro) | Date: 07-Jul-2026 |
  Classification: Confidential` string as page 4); legend strip `y=74 h=46` (`#fbfbfb`/`#d5d5d5`,
  font `#555555`, value `LEGEND`).
- Notes box at the bottom of every page: `#fffdf3`/`#d6b656`, font `#5b4b12`,
  `align=left;verticalAlign=top;spacingLeft=12;spacingTop=8`.
- No `fontFamily`. Size ladder 18 title / 13 band labels / 12 group captions / 11 component boxes /
  10 edge labels. `—`, `·`, `→`, `×` and circled numerals as separators — already the file's idiom.
- Palette per role, unchanged: Client `#dae8fc`/`#6c8ebf` · Gateway `#ffe6cc`/`#d79b00` ·
  Services `#d5e8d4`/`#82b366` · Messaging `#fff2cc`/`#d6b656` · Data `#e1d5e7`/`#9673a6` ·
  Platform `#f5f5f5`/`#666666` · External/SaaS `#ffffff`/`#999999` +
  `dashed=1;dashPattern=6 6;fontStyle=2`. **New:** assumption / to-be-confirmed
  `#fff2f0`/`#b85450`, used only for the Policy Administration System (see Open Items).
- Component boxes `rounded=1;whiteSpace=wrap;html=1;arcSize=10;fontSize=11`. Group / environment
  backdrops
  `rounded=0;html=1;dashed=1;dashPattern=8 8;fillColor=#f7f7f7;strokeColor=#b3b3b3;fontSize=12;fontStyle=1;align=left;verticalAlign=top;spacingLeft=10;spacingTop=6;fontColor=#555555`.
  Declare a backdrop **before** its contents so z-order puts it behind; children use `parent="1"`
  with absolute coordinates (no relative-geometry arithmetic).
- Edges `edgeStyle=orthogonalEdgeStyle;rounded=0;html=1;fontSize=10;labelBackgroundColor=#ffffff`.
  Three arrow semantics, per MSAG slide 9 ("different shades to represent internal and external
  communication"):
  - `strokeColor=#4d4d4d` solid — internal flow
  - `strokeColor=#1f3b57;strokeWidth=2` — cross-boundary / external traffic (MSAG "broad arrow")
  - `strokeColor=#8c8c8c;dashed=1;endArrow=open` — cross-cutting / governance / deferred

  `jumpStyle=arc;jumpSize=8` on any edge crossing a band. Edge labels are pinned `edgeLabel` children
  with an `<mxPoint as="offset">`, as on page 4.
- `gridSize=10`; equal gaps; corners aligned; top-down and left-to-right reading (MSAG summary).

**MSAG devices added** (hybrid style — existing palette plus the standard's own devices): scope
boundary · letter/number component tags so SAD prose can cite blocks (slide 8) · `shape=cloud` for
Internet connectivity (slide 15) · left-side band labels in the band's own colour (slides 14–15) ·
cross-cutting concerns as one right-hand column (slide 15) · numbered sequence tags on flows
(slide 4) · minimum arrows · legend on every page.
